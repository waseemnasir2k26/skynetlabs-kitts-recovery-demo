# Kitts Recovery Services — Landing Page Demo

5-variant speculative landing page build for **Kitts Recovery Services** (PNW peer support & recovery practice). Built by **SkynetLabs** for client pitch.

## Live

- Live: https://skynetlabs-kitts-recovery-demo.vercel.app/
- Variants: `?v=v1`...`v5` or use top-right switcher

## Variants

| # | Name | Vibe | Palette |
|---|------|------|---------|
| V1 | Tideline Editorial | magazine-quiet, navy/bone, pull-quote driven | ink · moss · brass · bone |
| V2 | Forest Cathedral Cinematic | full-bleed misty canopy, slow scroll, cinematic | blackgreen · evergreen · fern · mist |
| V3 | Misty Minimal | negative space, single line per fold, soft fog | slate-navy · teal-stone · fog · linen |
| V4 | Mossbound Magazine | editorial grid, drop caps, fern dividers | moss-deep · sage · driftwood · ochre |
| V5 | Northern Tide Brutalist | heavy serif slabs, exposed grid, navy/teal blocks | deep navy · deep teal · kelp · sand |

## Stack

- Static HTML + Tailwind CDN (zero build)
- Google Fonts: Fraunces, Cormorant Garamond, EB Garamond, Inter, JetBrains Mono
- Unsplash CDN photography
- Deployed via Vercel

## Source content

- Copy + service tiers + booking links scraped from client's existing Google Sites: https://sites.google.com/view/kitts-recovery-services/home
- Founder: Majesta (Jessie) Kitts, EdD, MPH, CPRS
- Booking platform: HeyPeers
